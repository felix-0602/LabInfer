审美拆解：这些图为什么高级

参考图按你发送的顺序编号 R1–R13；open-claude-ui 记为 OCU。

P1 · COLOR

无彩为底，只留一种强调色

画面九成是黑、白、银，饱和色只有一种钴蓝。颜色少，所以每一处蓝都被看见；R5 只用一抹红，红就成了视觉焦点。

R1 R2 R3 R4 R5 R8 R9 R13
P2 · SCALE

超大字当结构，极小字当肌理

标题被放大到撑满画面、被裁切、被描边、压在主体后面；旁边配 6–8px 的微型说明字。两种尺度同时出现，产生张力和层次。

R1 R2 R3 R4 R6
P3 · INSTRUMENT

测量仪器的语言

十字准星、刻度尺、坐标编号、序列号、角标框。画面因此显得「被测量过」，带着理性和精确感，这也是科技感的真正来源，而不是霓虹光效。

R2 R3 R5 R7 R10 R11 R12
P4 · MATERIAL

一个高质感物体当锚点

铬银、液态金属、玻璃球、碎晶。反射材质本身就带光影和细节，一个物体就能撑起整张画面，其余元素都围绕它排布。

R2 R6 R10 R11 R13
P5 · ORDER / BREAK

秩序与破坏并置

严格的网格和对齐，叠加碎裂、故障、半调、折痕。只有秩序会显得呆板，只有破坏会显得混乱，两者并置才有节奏。

P6 · RESTRAINT

克制：字体少、边框少、留白多

R6 只有白字、黑底和一个物体。OCU 的做法与之相通：0.5px 发丝线、4 级低对比表面、单层闭合边框，不叠框、不堆阴影。

02

逻辑匹配：手法对应到我们的功能

原则：每个视觉手法都要对应一个真实功能，不放纯装饰。

参考里的手法在 LabInfer 中对应什么
铬银 / 液态金属物体（P4）→银镜反应就是在玻璃上镀出一层银镜。所以主视觉物体就是银镜试管（GEN-01，Blender 渲染）：材质不是装饰，而是实验本身。
十字准星、刻度尺（P3）→M2 坐标校准的真实操作对象：校准点就是十字准星，坐标轴就是刻度尺，分析图顶部的温度尺把 1/T 换回 °C。仪器语言在这里不是装饰，而是功能。
玻璃球 + 球心十字（R10–R12）→M2 拖动校准点时出现的放大镜，用来精确对准刻度。
单一强调色（P1）→颜色有固定语义：钴蓝 = 机器读出或代码算出的数据（识别结果、提取点、拟合线、推演），墨黑 = 原始资料和文献，红 = 异常，且只用于异常（取自 R5 的那一抹红）。
超大字（P2）→每屏最多一个海报尺度的元素，必须是这一屏最重要的信息：封面的 LABINFER，分析页的 Ea 数值。
微字、序列号（P2 / P3）→微字全部用真实元数据：point_id、DOI、图号、schema 版本、像素坐标读数。参考图里的伪文字放在工具里就是噪音，所以不用。
秩序与破坏（P5）→M2 的「原图 / 提取层 / 叠加」切换，就是把曲线从截图里剥离出来。碎裂质感只出现在封面和导出页头图。
克制（P6 · OCU）→工作台用发丝线分区、单层边框、4 级表面；动效用 OCU 的手感参数：校准点吸附 120ms、面板滑入 300ms、按钮按下回弹。

除封面外，物件都是通用的科研意象，不绑定银镜反应；换成任何实验模板，画面都成立。物件统一用铬银 + 钴蓝两种材质，放在功能区之外，配「OBJ. 编号 + 英文名 + 寓意」的博物馆标签。

总判断：海报在边缘，工具在中心。参考图都是海报，海报要的是冲击力；工具要的是长时间看不累。所以强烈的表达只放在封面、空状态、关键数字和导出页这几处，工作区保持安静，仪器语言只在承担功能的地方出现。

质感层：三种来源，只用在情绪区

功能区（表格、校准画布、图表、结论卡片）保持干净，信息优先。质感只放在封面、侧栏底部、空状态、页面留白和导出页，负责情绪和审美锚点。

锚点构图：每件锚点物件都按同一套图层构图，全部由一张透明 PNG 实时派生（storyboard.js 的 ANCHOR_FX）。秩序层是超大描边词、过中心的刻度轴、角标框、引线标注、编号与条码；破坏层是钴蓝剪影套印错位、半调网点剪影、水平切片错位（偶尔抖动）、碎片、钴蓝压印色块、扫描线。破坏只发生在锚点区内，不碰功能文字。

印刷秩序纹样：功能区的边缘用印刷品的生产标记，包括套准标记、色条、裁切线、切割垫网格，以及状态栏的条码。它们让页面像一份被精确制作出来的文件，但不进入内容本身。
